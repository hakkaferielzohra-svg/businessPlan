## 🚀 Overview
**ClearPay Financial** is a complete, interactive 40-slide business plan presentation built as a standalone modern web application using **HTML5, Vanilla CSS3, and ES6 JavaScript**. 

Designed specifically for academic submission and pitch presentation, the app includes single-slide stage navigation, a 40-slide grid overview dashboard, a live progress indicator, custom KPI metric cards, embedded financial tables, and a clean **Print-to-PDF** export mode.

## 🛠️ How to Run

1. Ensure all three files (`index.html`, `style.css`, `main.js`) are saved in the same directory.
2. Double-click **`index.html`** or drag and drop it into any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox).
3. The presentation will open instantly with zero installation or build steps required.

## ⌨️ Interactive Controls

* **Next Slide:** Click the **Next** button, press the → (Right Arrow) key, or use the slide dropdown selector.
* **Previous Slide:** Click the **Previous** button or press the ← (Left Arrow) key.
* **Grid Overview:** Click **All Slides** in the top-right header or press G to view all 40 slides at a glance and jump instantly to any section.
* **Section Navigation:** Click any of the 5 section tabs at the top of the header to jump straight to the start of that part.
* **Export PDF / Print:** Click **Export PDF** in the top header to generate a clean, paginated print layout of all 40 slides for physical submission or PDF saving.
* **Close Modals:** Press Esc to close the grid view.
